# AI-SUBMITION

Artificial Intelligence Practical Lab Submissions & Experiments by Khatri Om Kumar.

## 📌 Contents

### 1. Search Algorithms (Romania / City Map)
- **Breadth-First Search (`breadth_first.py`)** - Uninformed search exploring level by level.
- **Depth-First Search (`depth_first.py`)** - Explores branch as deep as possible before backtracking.
- **A* Search (`astar_search.py`)** - Heuristic-driven search finding the optimal path.
- **City Map & Data (`city_map.py`, `cities.py`)** - Graph representation and straight-line heuristic distances.

### 2. Hill Climbing Algorithms (N-Queens Problem)
- **Steepest-Ascent Hill Climbing (`steepest_hill.py`)**
- **First-Choice Hill Climbing (`first_choice_hc.py`)**
- **Stochastic Hill Climbing (`stochastic_hc.py`)**
- **Random-Restart Hill Climbing (`restart_hill.py`)**
- **Utilities & Experiment Benchmarks (`nqueens_utils.py`, `queens_common.py`, `run_experiments.py`)**

### 3. Reports & Documentation
- `AI_KHATRI_OM_FINAL.PDF` / `AI_PRACTICLE_SUBMITTION_KHATRI_OM_KUMAR.PDF`
- `complete_lab_submission.html` / `om_khatri_lab_report.html`
- PDF Generation Scripts (`generate_complete_submission.py`, `generate_unique_pdf.py`)

## 🚀 Usage

Run any algorithm directly:
```bash
python astar_search.py
python breadth_first.py
python depth_first.py
python run_experiments.py
```
