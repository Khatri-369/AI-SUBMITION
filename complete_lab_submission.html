➢ Hill Climbing Variants on the 8-Queens Problem


Problem Statement :

Represent a chessboard using an array of length 8 where the index is the column and the value is the row of the queen. Example: [4,6,1,5,2,0,3,7]. One queen must exist in every column. The heuristic h(n) is the number of attacking pairs of queens. The goal state has h(n)=0.

3. Why does Steepest Ascent get stuck?

Answer:

Steepest Ascent gets stuck because it only looks at the current position and its immediate neighbours.

• Sometimes it reaches a local optimum. This means:

• The current board is not the solution, but none of its neighbouring boards is better.

• So the algorithm stops because it cannot find a better move.

• For example, suppose: Current h = 1 and every neighbouring board has h ≥ 1. The algorithm says, "There is no better move," and terminates, even though the actual solution requires h = 0.

• Steepest Ascent does not allow a temporarily worse move to escape.


4. How does Random Restart overcome local optima?

Answer:

Random Restart doesn't try to escape the local optimum directly.

• Instead, it throws away the stuck solution and starts fresh from a completely new random board.

• Start → climb → local optimum → stuck → Restart with new random board → climb again.

• By repeating restarts, it is mathematically likely to start from a basin of attraction that leads directly to the global optimum (h = 0).


5. Why can Stochastic Hill Climbing outperform Steepest Ascent?

Answer:

Steepest Ascent always greedily chooses the single best immediate move, which often drives the search into a steep local optimum trap. Stochastic Hill Climbing randomly selects among all improving neighbours. Even if a move gives a smaller immediate reduction in h, it can lead along a different branch of the state space that avoids traps and reaches h = 0.

All four algorithms were tested on the 8-Queens problem. The three standard hill-climbing methods frequently get trapped in local optima, whereas Random Restart guarantees completeness given sufficient restarts at the cost of higher cumulative evaluations.
